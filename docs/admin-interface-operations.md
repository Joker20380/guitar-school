Обновление 2026-09-13: django-jazzmin 3.0.5, боковая навигация, быстрые ссылки на сайт, курсы, заявки и инструкцию. Светлый, тёмный и автоматический режимы. Золотая палитра и знак G повторяют существующую шапку сайта; SVG используется также для иконки вкладки. Добавление — залитая кнопка, изменение/просмотр — контурная с отступом.

Админка использует русский язык через config/admin_locale.py после LocaleMiddleware; язык публичного сайта и его переключатель сохраняются. Ссылка /admin/help/ по-прежнему защищена admin.site.admin_view; инструкция адаптирована к темам, мобильному экрану и печати. Переопределение login.html сохраняет скрытый next при входе. Модели, права, приватные загрузки, отправка приглашений и действия над данными не изменены. Миграций нет.

Стиль: static/css/phoenix-admin.css. Настройки: JAZZMIN_SETTINGS и JAZZMIN_UI_TWEAKS в config/settings.py. Значок: static/images/phoenix-admin-mark.svg. При изменении статики выполнять collectstatic; WhiteNoise автоматически использует имена с хешем. Не добавлять query string в custom_css.

Проверка: 32 существующих теста в локальной SQLite и в отдельном серверном образе без сети. Браузер: вход с next, все режимы темы, кнопки действий, формы курса/урока/преподавателя/заявки/доступа/материала/пользователя, добавление inline-урока, автоматический slug, файловые поля, виджет навыков преподавателя, мобильные страницы и печать инструкции.

Образ guitar-school-web:admin-20260913 основан на текущем рабочем образе с добавлением локального wheel django-jazzmin 3.0.5; остальные версии зависимостей сохранены. requirements.txt содержит эту же фиксацию для будущей штатной сборки. Предыдущий образ: guitar-school-web:before-admin-20260913.

Перед установкой исходники и manifest сохраняются в backups/admin-jazzmin-<UTC timestamp>. Откат: восстановить существовавшие файлы по manifest из source/, удалить только созданные обновлением файлы с before=null, вернуть сохранённый предыдущий образ как guitar-school-web:latest, выполнить collectstatic и пересоздать только web через docker compose up -d --no-deps --force-recreate web. База и пользовательские файлы не откатываются и не затрагиваются.

## Совместимость WhiteNoise и рабочая проверка

Jazzmin 3.0.5 запрашивает `static("vendor/bootswatch")` как базовый каталог тем. Строгий manifest WhiteNoise принимает только файлы и вызывал 500 на основной админке. `config/static_storage.py` обрабатывает ровно этот каталог; реальные файлы продолжают использовать строгий manifest и хеши. При обновлении Jazzmin перепроверить эту совместимость. Дополнительная копия settings до исправления: `backups/admin-static-20260913-095413/`. При полном откате обновления удалить также созданный `config/static_storage.py`.

После исправления проверены реальные авторизованные HTTP-ответы работающего Gunicorn: `/admin/`, список курсов, добавление курса и урока, инструкция — 200. Временная проверочная сессия удалена. Отдельно проверены восемь страниц через Django, запрет инструкции анонимному посетителю, английский публичный сайт и русская админка. HTTPS-вход проверен браузером в светлом и тёмном режимах; иконка и хешированная статика загружаются без ошибок. Основная копия обновления: `backups/admin-jazzmin-20260913-095237/`.
