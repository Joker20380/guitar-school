## Решения этого этапа (не прежнее утверждение Эли)

- Текущий Django, URL без языкового префикса сохраняются, язык через cookie; EN до явного выбора RU.
- Единая отдельная страница записи; общий CTA без направления, карточки с явным параметром.
- Обязательны имя, направление, международный телефон. По умолчанию WhatsApp; дополнительные контакты необязательны, но валидируются при заполнении.
- Необязательное фото отзыва; новые отзывы ученика скрыты до модерации. Публикация прежних отзывов сохраняется.
- Public Telegram отдельно от адресата уведомлений; без подтверждения ссылку не показывать.
- Только синтетические пользователи и отключённые внешние уведомления.
